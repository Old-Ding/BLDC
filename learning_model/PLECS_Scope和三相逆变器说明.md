# PLECS Scope 和三相逆变器说明

## 1. 你截图里的 Scope 是什么

你第一张图里的窗口 `bldc_six_step_learning/Scope` 就是 PLECS 的示波器。

它不是电路里的物理元件，而是仿真波形窗口，用来显示模型里接进去的信号。你看到的四栏含义是：

| Scope 区域 | 含义 | 入门先看什么 |
|---|---|---|
| `Stator Phase` | 三相定子电流 | 电流是不是按相轮流导通 |
| `Back EMF` | 三相反电动势 | BLDC 梯形反电动势形状 |
| `Motor` | 转子速度 | 启动后速度是否上升并稳定 |
| `Machine` | 电磁转矩 | 六步/梯形控制下的转矩脉动 |

如果 Scope 窗口被关掉：

1. 回到 PLECS 主模型。
2. 找到右侧或上方的 `Scope` 小方块图标。
3. 双击 `Scope`。
4. 再点击 Run，波形会重新显示。

## 2. 为什么看不到三相逆变器内部

你第二张图的 `2-Level IGBT Conv.` 是 PLECS 官方库里的封装模块。它把三相桥的 6 个 IGBT、反并联二极管、DC 母线和三相输出封装成一个图标。

所以在主图里你只看到：

```text
左侧：三相输出端
上方绿色输入：开关脉冲 pulses
上/下：DC+ 和 DC- 母线
```

这不是你操作错了，而是库模块有意隐藏了内部功率器件。

## 3. 2-Level IGBT Conv. 的内部等效拓扑

我已经把它展开成一张图：

```text
D:\1codex\BLDC\learning_model\three_phase_inverter_topology.svg
```

等效结构是：

```text
DC+
 |          |          |
A上        B上        C上
 |          |          |
 U          V          W    -> 接 BLDC 三相
 |          |          |
A下        B下        C下
 |          |          |
DC-
```

每一相都是一个半桥：

```text
A 相 = A上管 + A下管，中点输出 U
B 相 = B上管 + B下管，中点输出 V
C 相 = C上管 + C下管，中点输出 W
```

## 4. 和六步换相的关系

六步换相不是六个开关一起乱动，而是每一步只选两个开关：

| 步 | 导通 | 悬空相 |
|---|---|---|
| 1 | A 上 + B 下 | C |
| 2 | A 上 + C 下 | B |
| 3 | B 上 + C 下 | A |
| 4 | B 上 + A 下 | C |
| 5 | C 上 + A 下 | B |
| 6 | C 上 + B 下 | A |

你现在看官方模型时，先把 `2-Level IGBT Conv.` 理解成这个三相桥。等我们下一步做真正的霍尔六步模型时，就把 `pulses` 换成清晰的六步换相表。
