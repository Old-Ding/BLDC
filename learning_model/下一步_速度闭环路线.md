# 下一步：从开环六步到速度闭环

当前模型只做开环六步换相：

```text
Hall -> 换相表 -> PWM 固定占空比 -> 三相桥
```

下一步速度闭环不要改功率级，只在控制层增加：

```text
Hall 边沿/转速反馈
  -> 速度估算
  -> 速度 PI
  -> duty
  -> PWM 生成器
```

分层原则：

- 霍尔解码仍然只产生扇区/换相时刻。
- 速度 PI 只输出占空比。
- PWM 调制只执行占空比。
- 故障状态机统一决定是否允许输出。

建议成功标准：

1. 给定转速阶跃时，实际转速能跟随。
2. 加负载后，duty 自动增大。
3. 堵转或非法 Hall 时，输出关断。
4. 示波器能看到 `target_speed`、`actual_speed`、`duty`、`hall_state`。
