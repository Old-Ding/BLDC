# 00 BLDC 完整学习路线：从真实电机现象到固件、无感与 FOC

完整的 BLDC 教程不能只给出六步换相表，也不能一开始就把三相桥、Hall、速度环、保护、无感和 FOC 全塞进一张图。

前一种写法让读者会背位模式，却解释不了相电流为什么产生转矩；后一种写法信息密度过高，出了问题也不知道该查功率级、电机参数、反馈还是控制器。

这套课程采用一条可验证的路线：先在 PLECS 中看到真实功率级和电机响应，再逐层拆开物理关系与控制职责；Hall 六步闭环完成后，才进入固件、无感六步和 FOC。

配套仓库：[https://github.com/Old-Ding/BLDC](https://github.com/Old-Ding/BLDC)

## 一条主线贯穿所有章节

BLDC 系统可以沿同一条能量与信息链理解：

```text
直流母线
  -> 三相逆变器
  -> 三相电流
  -> 反电动势与电磁转矩
  -> 机械转速和位置
  -> Hall / 反电动势 / 编码器反馈
  -> 换相、电流和速度控制
  -> 三相逆变器
```

每个章节只新增当前需要的一层，但不会切断这条链。读者在任何一篇里都应能回答：输入来自哪里，内部发生了什么，输出给谁，应该观察哪张图或哪份数据。

## 工具为什么要分工

| 工具 | 负责什么 | 证据边界 |
|---|---|---|
| PLECS / Simulink | 开关功率级、电机电磁量、机械负载和完整闭环 | 主图来自真实模型求解，不由信号示意图替代 |
| MATLAB | 参数计算、控制器设计、批量扫参和 PLECS CSV 后处理 | MATLAB 图必须说明数据来源和模型层级 |
| C | 换相、Hall、测速、PI、保护和状态机 | C 源码需要编译和测试后才能声称可执行 |
| Python / PowerShell | 调用工具、编排场景、导出数据和报告 | 自动化只负责运行与留证，不重复实现技术判断 |

这也是教程的证据顺序：

```text
模型或源码
  -> 命名场景
  -> CSV / trace
  -> PLECS Scope 主图
  -> MATLAB 对比或扫参
  -> 指标与 PASS/FAIL 报告
  -> 教学正文
```

文章不是最先生成的文件。正式章节先完成实验包，正文再教读者如何读懂同一份证据。

## 阶段 A：功率级与电机物理基础

| 篇章 | 核心问题 | 读完后应能解释 |
|---:|---|---|
| 01 | 相电流怎样形成转矩，负载过大为何失速 | `电流 -> 转矩 -> 净转矩 -> 速度` |
| 02 | 三值相命令怎样变成六路门极信号 | 上桥、下桥、悬空和直通的电流路径 |
| 03 | 机械角度、电角度和极对数怎样关联 | 机械转一圈为什么可能经历多个电周期 |
| 04 | 梯形反电动势怎样参与转矩形成 | `ea*ia + eb*ib + ec*ic` 的符号和大小 |
| 05 | 120° 导通为什么得到六步换相表 | 每个扇区的正相、负相和悬空相 |

这一阶段不急着调 PI。先把桥、电流、反电动势、转矩和速度之间的因果关系固定下来，后面的控制算法才有明确对象。

## 阶段 B：Hall 六步闭环

| 篇章 | 主题 | 主要实验 |
|---:|---|---|
| 06 | 开环电角度推进 | 固定周期六步换相 |
| 07 | 静止启动与加速斜坡 | 初始定位、低频起步和斜坡边界 |
| 08 | 开环失步 | 正常与负载扰动失步对比 |
| 09 | Hall 序列和方向 | 6 个合法状态、非法状态和跳变 |
| 10 | Hall 换相与安装偏置 | 正确、错位和反向三组场景 |
| 11 | PWM 与死区 | duty 变化、有效电压和桥臂安全 |
| 12 | Hall 边沿测速 | 计时器量化、低速更新和超时 |
| 13 | 速度 PI 与抗饱和 | 目标阶跃、负载阶跃和限幅恢复 |
| 14 | Hall 六步完整闭环 | 启动、稳态、扰动、非法 Hall 和过载套件 |

阶段 B 的结束标志不是“速度曲线看起来平滑”，而是所有关键模块在同一个 PLECS 模型中形成闭环，并且每个场景有数据、指标和边界。

## 阶段 C：嵌入式固件工程

| 篇章 | 主题 | 必须拿出的证据 |
|---:|---|---|
| 15 | C 编译与主机单元测试 | 编译命令、测试源码、返回码和报告 |
| 16 | 定点化和溢出 | Q 格式、饱和边界、与浮点结果对比 |
| 17 | Hall、ADC、PWM 映射 | 物理量到计数值的公式和边界测试 |
| 18 | ISR、状态机、后台任务 | 调用链、数据所有权和执行周期 |
| 19 | 保护锁存与重启 | 故障注入、状态迁移和清故障条件 |
| 20 | 参数标定与可观测量 | 相序、Hall 偏置、电流零点和保存结果 |
| 21 | SIL、CI、HIL | 自动回归日志和硬件在环接口 |
| 22 | 硬件上电与验收 | 限流电源、示波器、温升和保护动作 |

这一阶段把“仿真逻辑正确”逐步推进到“C 代码可编译、数值范围可证明、实时职责清楚、硬件波形可验收”。任何一步都不能由 Python 示意模型代替对应工具链证据。

## 阶段 D：无感六步

| 篇章 | 主题 | 关键边界 |
|---:|---|---|
| 23 | 悬空相反电动势过零 | 为什么必须测悬空相 |
| 24 | 消隐、滤波和比较阈值 | PWM 边沿怎样制造假过零 |
| 25 | 开环启动到无感接管 | 零速没有反电动势时如何启动 |
| 26 | 换相延迟与提前角 | 过零后何时换相 |
| 27 | 低速和高速范围 | 噪声、采样和计算延迟限制 |
| 28 | 无感完整闭环 | 接管、目标阶跃和负载扰动 |

## 阶段 E：FOC 扩展

| 篇章 | 主题 | 关键问题 |
|---:|---|---|
| 30 | Clarke/Park | 三相量怎样变成旋转坐标系直流量 |
| 31 | d/q 电流环 | 电流误差怎样变成电压指令 |
| 32 | SVPWM | dq 电压怎样变成三相占空比 |
| 33 | FOC 速度环 | 速度误差怎样给出 q 轴电流参考 |
| 34 | 电压限幅与弱磁 | 高速时反电动势为何受母线限制 |
| 35 | FOC 完整模型 | 电流环、速度环和调制怎样联调 |
| 36 | 六步与 FOC 比较 | 成本、噪声、效率和软件复杂度怎样取舍 |

FOC 放在最后，不是因为它不重要，而是因为功率级、电机参数、采样、保护和固件分层都可以从前面复用。先建立这些共同基础，FOC 不会变成一组脱离物理对象的公式。

## 每篇正式实验章怎样验收

| 门槛 | 最低要求 |
|---|---|
| 模型 | PLECS/Simulink 模型或明确边界的计算脚本 |
| 参数 | 数值、单位、用途和关键限制 |
| 场景 | 至少两个有区分度的命名场景 |
| 数据 | 每个场景的 CSV、trace 或导出表 |
| 图 | 每个重要结论对应真实工具图 |
| 报告 | 指标、PASS/FAIL 或教学观察边界 |
| 复现 | PowerShell 命令、期望输出和失败解释 |
| 教学 | 读者能独立从证据得到同一结论 |

缺少其中任一项时，章节只能标为路线、导读或草稿，不能用更长的文字补偿缺失的实验。

## 如何解读这篇路线

这是一篇课程入口，证据是章节依赖、工具职责和发布门槛，不是某个控制算法的实验结果。参数能否用于硬件、保护是否完整、无感能否可靠接管、FOC 是否满足高速要求，都要在对应正式章节中用模型、代码或硬件数据回答。
