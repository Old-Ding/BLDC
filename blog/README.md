## 文章完成标准

每篇文章需要包含：

1. 一个核心问题。
2. 一个最小数据流。
3. 对应模型、代码或 MATLAB 脚本。
4. 真实 Scope、导出数据、脚本输出或参数表。
5. 这个结果证明什么，以及不证明什么。
6. 可复制的 PowerShell 复现命令。
