# 第 08 章三轮复核记录

## 高级工程师复核

- 三场景共用同一 IGBT bridge 和 BLDC Machine，只改变频率斜坡与机械负载。
- 负载阶跃使用 PLECS 原生 Step 直接驱动 Torque 端口；已用扰动前重合、扰动后轨迹分离排除“只改 CSV 标签”的错误。
- 同时保留折回相位差和未折回累计滑移，诊断判据使用后者。
- 3 场景均返回 701 点、15 路，3/3 PASS；PASS 明确为失步现象复现。

## 高级 UI 工程师复核

- PLECS 原生 Scope 与 MATLAB 后处理图分别标注来源。
- MATLAB 图按输入频率、机械响应、累计滑移和转矩因果顺序排列。
- 三场景颜色在四层图中保持一致，图例放在外侧，不遮挡波形。

## 高级心理学家复核

- 开头先纠正“转速上升就是启动成功”的直觉误区。
- 在公式前解释折回相位差为什么会隐藏累计失步，再引入滑移圈数。
- 结果表后单独解释三个 PASS 的含义，避免把诊断通过误读为控制通过。
- 结尾只引出 Hall 状态，不展开后续 PWM 或速度环路线。
