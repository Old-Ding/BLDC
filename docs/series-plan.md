# BLDC 教程完整规划

这份规划用于约束整个教程的范围。当前优先完成第一阶段六步 BLDC 最小闭环，第二阶段再写工程化，FOC 独立成进阶系列。

## 总体路线

```text
PLECS 建系统现象
  -> C 代码表达唯一职责层
  -> MATLAB 做计算、扫参和图表
  -> Markdown 写成可复现教程
  -> CSDN 只负责最后转换和草稿保存
```

## 单篇文章合同

每篇文章都按同一合同推进：

1. 只回答一个核心问题。
2. 明确本篇不解决的内容。
3. 先给最小数据流，再解释代码和模型。
4. 结论必须来自 PLECS、MATLAB、C 代码、表格或显式假设。
5. 保护、状态机、控制器、功率级不混写。
6. 不做重复防护；如果确实需要重复防护，先说明原因并确认。
