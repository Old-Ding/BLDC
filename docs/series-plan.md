# BLDC 技术教程实施总纲：证据先行版

这套教程以“读者能解释、能复现、能定位问题”为完成标准。主线先完成 Hall 六步闭环，再进入固件、无感六步和 FOC；不同控制路线不在入门阶段混写。

## 总体方法

每个正式实验章遵循同一顺序：

```text
可观察问题
  -> 物理或控制模型
  -> 参数与场景
  -> PLECS/Simulink 主实验
  -> CSV 和指标
  -> MATLAB 计算、扫参或后处理
  -> C 语言唯一职责层
  -> 边界与复现
```

工具职责固定如下：

| 工具 | 唯一职责 | 不能替代的证据 |
|---|---|---|
| PLECS / Simulink | 开关功率级、电机电磁模型、机械响应、系统联调 | MATLAB 信号示意不能替代真实功率级和电机响应 |
| MATLAB | 参数计算、CSV 后处理、批量扫参、控制器设计和交叉验证 | MATLAB 图不能冒充 PLECS Scope |
| C | 换相、Hall、测速、PI、状态机、保护等可移植控制核心 | C 源文件不能直接证明 MCU 已可上板 |
| Python / PowerShell | 调用工具、编排场景、导出证据、生成报告 | 自动化脚本不拥有技术 PASS/FAIL 逻辑以外的重复判断 |

## 发布门槛

正式章节进入 GitHub/CSDN 前必须同时具备：

1. 可运行模型或脚本。
2. 参数表，包含数值、单位、用途和关键限制。
3. 至少两个有区分度的场景。
4. PLECS/Simulink Scope 主图，或明确标注边界的其他真实工具图。
5. 图背后的 CSV、trace 或导出数据。
6. 指标和 PASS/FAIL 报告，或明确说明“教学观察、不作 PASS/FAIL”。
7. PowerShell 复现命令和常见失败解释。
8. 工程、视觉、读者理解三轮实证复核。
